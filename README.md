# Stammdatenpflege-Datenqualität
Power BI Dashboard zur Analyse und Überprüfung der Stammdatenqualität. Das Dashboard zeigt fehlerhafte Datensätze, mögliche Duplikate und die Verteilung der Artikel nach Kategorien.
# Stammdatenqualität – Power BI Dashboard

## 📊 Projektbeschreibung

In diesem Projekt habe ich ein Power BI Dashboard zur Überprüfung der Stammdatenqualität erstellt.

Das Ziel ist, Datenfehler schnell zu erkennen und einen besseren Überblick über die vorhandenen Artikeldaten zu bekommen.

Das Dashboard zeigt unter anderem:
- Anzahl der Artikel
- Fehlerfreie Datensätze
- Datensätze mit Fehlern
- Mögliche Duplikate
- Artikel nach Kategorie
- Datenqualität in Prozent
- Fehlergründe, z. B. fehlender Preis oder Lieferant

## 🛠️ Verwendete Tools

- Microsoft Power BI
- Excel
- SQL / MySQL

## 🔍 Datenqualität

Für die Prüfung der Stammdaten habe ich verschiedene Kriterien verwendet. 
Zum Beispiel werden fehlende Werte bei Preis, Lieferant oder Lagerbestand erkannt.

Zusätzlich habe ich mögliche Duplikate anhand von Artikelnamen und weiteren Merkmalen geprüft.

## 📈 Dashboard

Das Dashboard bietet eine übersichtliche Darstellung der Ergebnisse und hilft dabei, Datenfehler schneller zu erkennen und zu prüfen.
